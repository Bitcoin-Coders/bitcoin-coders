# Laboratórios Bitcoin Coders

Esta pasta reúne experimentos técnicos e reproduzíveis desenvolvidos para acompanhar artigos, cursos e pesquisas do Bitcoin Coders.

Cada laboratório possui seu próprio README, com:

- objetivo;
- metodologia;
- requisitos;
- instruções de execução;
- resultados esperados;
- limitações do experimento.

## Laboratórios disponíveis
